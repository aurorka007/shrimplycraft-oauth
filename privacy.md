# Privacy Policy — ShrimplyCraft Backups

**Last updated: October 26, 2026**

## Overview

ShrimplyCraft Backups is a private backup solution used by the administrator of the ShrimplyCraft Minecraft server network.

The application uses Rclone and Google Drive to securely store and manage encrypted server backups.

## Data We Process

Backups may contain Minecraft player identifiers, gameplay statistics, permissions, server configuration files, and administrative account data.

The application is not offered as a public service.

## Google Drive Access

Google Drive access is authorized by the administrator through Google OAuth.

Rclone is used to upload, list, download, verify, and manage backup files in the designated backup storage location.

Google Drive access is used exclusively for backup management and recovery, not for advertising, profiling, or unrelated purposes.

## Data Storage and Security

Backup files are intended to be encrypted locally using Rclone Crypt before being uploaded to Google Drive.

OAuth credentials and encryption keys are stored separately from publicly accessible files.

Backup access is restricted to the authorized administrator.

## Data Sharing

We do not sell Google user data or share it with advertisers or unrelated third parties.

Google Drive is used as the storage provider for encrypted backup files.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

## Data Retention and Deletion

Backup files are retained according to the administrator's backup retention settings and may be deleted when no longer needed.

The administrator can revoke Google Drive access through Google Account security settings.

## Contact

For questions about this application or its privacy practices, please contact the project administrator through the [GitHub repository](https://github.com/aurorka007/shrimplycraft-oauth).

Do not submit passwords, access tokens, or private backup data in public GitHub issues.
