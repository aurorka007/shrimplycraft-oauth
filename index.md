# ShrimplyCraft Backups

ShrimplyCraft Backups is a private backup solution for the ShrimplyCraft Minecraft server network.

The application uses Rclone and Google Drive to securely store encrypted backups of server databases and configuration files.

## Purpose

- Create and store backups of ShrimplyCraft server data.
- Encrypt backup files before uploading them to Google Drive.
- Allow the server administrator to restore data when necessary.
- Protect against data loss caused by server failures.

## Google Drive Access

Google Drive access is used exclusively for backup storage and management.

The application is intended for personal administrative use and is not offered as a public service.
